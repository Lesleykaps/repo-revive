# Publication Checklist

- [ ] `npm test` passes.
- [ ] `npm run pack:check` includes the installer, manifests, skill, README, license, privacy policy, and terms.
- [ ] `npx . codex --dry-run` identifies the expected location.
- [ ] Repository URL and version are correct.
- [ ] Sensitive files are absent from the npm tarball and Git history.
- [ ] GitHub repository is public and has a release/tag.
- [ ] npm package name remains available immediately before `npm publish`.

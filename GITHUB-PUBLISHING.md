# GitHub Publishing

This repository is ready for a public GitHub repository named `repo-revive`.

1. Run `npm test` and `npm run pack:check`.
2. Commit and push the repository.
3. Create a GitHub release/tag for each published version.
4. Authenticate with npm and run `npm publish` only when release publication is intended.

The package uses the unscoped npm name `repo-revive`, verified as available before this package was created. If it is claimed before publication, use a scoped name and update the README install command.

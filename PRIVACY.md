# Privacy Policy

Repo Revive is local-file-first. The npm installer copies packaged skill files to the local Codex skills directory. The skill examines only the repository and context provided to the active Codex task.

Repo Revive has no built-in telemetry, account system, remote API, credential collection, or data transmission. Any network or external-tool operation remains governed by the host agent and requires the authority appropriate to that operation.
